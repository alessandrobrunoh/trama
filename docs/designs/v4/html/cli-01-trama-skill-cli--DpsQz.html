# /trama
Use when the user names a Trama task
(TRM-128, PROJX-123…)
1. trama show <ID> --json
read task, subtasks, past decisions
2. trama link <ID> --thread <current>
if already linked: ask the user,
then trama sub <ID> "<title>" --link
3. trama status <ID> in-progress
never change any other status
4. after each turn that edits files:
trama sync <ID>
5. when you open a PR:
trama sync <ID> --pr <url>
6. before touching a file:
trama decisions --path <file>
7. time: trama sync also sends
active sessions as suggestions
