CONSTRUCTION
Construction and clear space
Built on a 4-unit module inside a 100-unit square: every edge lands on the grid. Two 60-unit frames with a 12-unit band, offset by 32. Each strand passes over the other once, with a 4-unit gap at every crossing.

GAP 4

The logomark is never smaller than 16px, and the horizontal logo never shorter than 20px. At 16–28px the band gets thinner and the gaps wider, so the weave still reads. The interface uses the same 4-unit module for spacing and icon grids.

WRITING THE NAME
Writing the name
Trama is one word with a capital T, in running text and in titles. It is Italian for weft, the thread that ties a fabric together, and for the plot of a play.
