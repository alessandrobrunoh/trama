Trama · v3 · complete product
Plan in Trama. Work in Delta.
Keep the record forever.
Trama is a cloud task manager (web + mobile) that connects to any issue tracker. Each task — and each subtask — links exactly one Delta thread. Work starts in Delta with the /trama skill: the agent reads the task, links its own thread and syncs a read-only record (summary, decisions, events, changes). Time spent is tracked per task.
The flow
1
Issue arrives
An issue on GitHub, GitLab or Jira is synced into Trama as a task. Or create it directly.
Trama cloud
2
Plan
Split it into subtasks, set status, priority, assignee and due date. People own the status.
Trama cloud
3
Start in Delta
Open a thread and type /trama TRM-128. The agent reads the task, its subtasks and past decisions from Trama.
Delta
4
Agent links it
The agent runs trama link with its own thread. Already linked? It asks you to create a subtask instead.
/trama skill
5
Record syncs
After each step the agent runs trama sync: summary, decisions, events, files and PR. Read-only, stale if it falls behind.
/trama skill
6
Review & close
PR reviewed and merged. You set Done; the summary and the time logged are posted back to the issue.
